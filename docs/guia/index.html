一
ようこそ · BIENVENIDA

Qué hay en tu ordenador

Tu sistema es CachyOS, una distribución basada en Arch Linux y optimizada para tu procesador. Encima tienes estas piezas:

🪟

Hyprland

Gestor de ventanas en mosaico, con las animaciones. Se configura en Lua, en ~/.config/hypr/.

🌙

Noctalia

La barra, el dock, el lanzador, las notificaciones, el bloqueo, los fondos y los colores automáticos.

色

Irokai

Une todo: estéticas, fondos (también animados), sonidos, animaciones, pantallas y un menú central. Abre el menú con Super+M.

🐱

Kitty + Fish + Starship

Terminal, shell y prompt. Los colores y el símbolo del prompt cambian con la estética.

📸

Btrfs + Snapper

Antes y después de cada instalación se guarda una instantánea del sistema, así que siempre puedes volver atrás.

🖥️

KDE Plasma (opcional)

Si lo instalaste con ./install.sh --con-plasma, tienes un segundo escritorio más clásico. Se elige al iniciar sesión.

心
La tecla Super es la de Windows. Si solo te acuerdas de tres atajos, que sean estos: Super+Espacio (abrir apps), Super+M (menú de Irokai) y Super+H (todos los atajos).

三
美学 · ESTÉTICAS

Una estética para cada fondo

Tus fondos están en ~/Imágenes/Wallpapers, con una carpeta por categoría. Cada carpeta tiene su estética, y al poner un fondo cambia todo el escritorio a la vez:

  • los colores (barra, terminal, apps, btop, cava);
  • el degradado de los bordes, el redondeo y la separación entre ventanas;
  • el tipo de animación;
  • el símbolo y los colores del prompt;
  • el dibujo de bienvenida de la terminal;
  • el tema de Spotify.

Da igual cómo cambies el fondo: con Super+N, con el panel de Noctalia o con el comando fondo. En todos los casos la estética se aplica sola.

Añade cualquier fondo: se configura solo ✨

Pon cualquier imagen (o vídeo) y Irokai hace el resto. Lee sus colores, elige la estética que mejor le va (retro si es neón, sakura si es rosa, manga si es blanco y negro…) y lo viste todo a juego: barra, bordes, terminal, VS Code y Spotify.

fondo añadir ~/Descargas/mi-foto.jpg          # una imagen
fondo añadir ~/Descargas/mis-fondos/          # una carpeta entera
fondo añadir https://ejemplo.com/imagen.png   # desde un enlace
fondo añadir ~/Vídeos/lluvia.mp4              # un vídeo: se pone como fondo animado

También puedes copiar tus imágenes en la carpeta ~/Imágenes/Wallpapers/mios (Super+M → «Añadir mis fondos» la abre) y ponerlas con Super+N.

Pantallas

Modos: juego, ahorro y luz nocturna

🎮 Modo juego · Super+G

Quita el desenfoque, las sombras y las animaciones pesadas, congela el fondo animado, silencia las notificaciones y pone el perfil de energía en rendimiento.

🔋 Modo ahorro · Super+B

Lo mismo, pero con el perfil de ahorro de energía: más horas de batería.

🌙 Luz nocturna · Super+F6

Tonos cálidos para descansar la vista por la noche.

Widgets del escritorio que se mueven

Pulsa Super+Shift+E: aparece una rejilla. Arrastra con el ratón el reproductor de música, el visualizador o cualquier widget a donde quieras. Con el botón + añades más (reloj, tiempo, calendario…). Pulsa Hecho para guardar.

Ajustes · Super+I

Un menú con todo lo configurable: estética automática, colores por fondo, colores de Spotify, sonidos, animaciones, cambio automático de fondo, modos, luz nocturna y widgets. También puedes editar a mano ~/.config/irokai/irokai.conf.

六
ターミナル · TERMINAL

La terminal sin miedo

Con unos 15 comandos haces el 90 % de las cosas. El prompt te dice dónde estás: 家 es tu carpeta personal, 文書 Documentos y 画像 Imágenes.

Moverte y ver archivos

ls  /  lt             # lista lo que hay / en forma de árbol
cd Documentos       # entrar en una carpeta (cd .. sube, cd solo vuelve a casa)
z guia              # salta a una carpeta que ya visitaste, por parte del nombre
yazi               # explorador de archivos en la terminal (q para salir)
cat archivo.txt     # ver un archivo (con colores)
micro archivo.txt   # editarlo: Ctrl+S guarda, Ctrl+Q sale

Crear, copiar, mover y borrar

mkdir proyectos      # crear carpeta
cp a.txt b.txt       # copiar (cp -r para carpetas)
mv a.txt proyectos/  # mover o renombrar
rm a.txt             # borrar: ¡no va a la papelera!
危
Nunca ejecutes sudo rm -rf, ni nada que hayas copiado de internet, sin entender qué hace. sudo significa «como administrador» y te pide la contraseña. No se ve mientras la escribes, y es normal.

Spotify, de dos maneras

Sin modificar Spotify (por defecto)

Spotify oficial, tal cual. Irokai le añade las teclas multimedia, el reproductor y el visualizador del escritorio, las letras en karaoke (Super+Shift+M) y el control desde la barra.

Con tema a juego (opcional)

Spotify se viste con los colores de cada fondo y gana portada a pantalla completa, letras emergentes, atajos y aleatorio mejorado. Usa Spicetify, que modifica la app de Spotify, algo que sus condiciones no permiten: actívalo solo si aceptas ese riesgo.

irokai spotify-tema activar      # lee el aviso y escribe ACEPTO
irokai spotify-tema desactivar   # Spotify vuelve a ser el original
spicetify backup apply           # si tras una actualización de Spotify desaparece el tema

En Super+I → «Colores de Spotify» eliges entre los colores de cada fondo o el tema fijo de cada estética.

Grabar la pantalla

Para vídeos rápidos usa irokai demo --grabar video.mp4 (abajo). Si quieres un programa completo de grabación y directos, instala OBS con sudo pacman -S obs-studio y añade la fuente Captura de pantalla (PipeWire).

Vídeos para TikTok en 1 comando

irokai demo --grabar ~/Vídeos/TikTok/demo.mp4   # 2 min: estéticas, fondos animados, menú, animaciones…

La demo se graba en un escritorio vacío, así que no sale nada personal. No toques el teclado mientras graba. Para pasarla a vertical (1080×1920) con fondo difuminado y título:

ffmpeg -i demo.mp4 -filter_complex "[0:v]fps=30,split[a][b];[a]scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,gblur=sigma=40[f];[b]scale=1080:-2[v];[f][v]overlay=(W-w)/2:(H-h)/2,format=yuv420p" -c:a aac tiktok.mp4
注
En TikTok, añade la música desde la propia app: si usas canciones con copyright fuera de ella, te silencian el vídeo. Y si algún día haces anuncios de pago, usa fondos que tengas derecho a usar.

九
言語 · IDIOMAS

Idiomas y teclado

El teclado está en español, con el inglés como segundo idioma. Cambias entre los dos con Alt+Shift, y la barra te muestra cuál está activo (ES/US). Para añadir más idiomas, edita ~/.config/hypr/config/inputs.lua:

kb_layout = "es,us,fr",   -- separados por comas

Escribir en japonés 日本語

irokai japones        # y después cierra sesión y vuelve a entrar

Ctrl+Espacio alterna entre español y japonés. Escribe en romaji (samurai), pulsa Espacio para elegir los kanji (侍) y Enter para confirmar.

Idioma de todo el sistema

sudo micro /etc/locale.gen                    # quita el # de la línea del idioma (p. ej. ja_JP.UTF-8)
sudo locale-gen
sudo localectl set-locale LANG=ja_JP.UTF-8     # y reinicia

Antes de instalarse, Irokai guardó una copia de tu configuración en ~/.local/share/irokai/copias/. Para restaurarla: tar xzf <copia> -C ~/.config
